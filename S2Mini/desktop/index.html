Réglages Tally Sony
Prototype · à valider sur l’A7 IV

Connexion directe en Bluetooth LE. Une LOLIN C3 Mini est nécessaire : la S2 Mini ne possède pas de Bluetooth.

Nom de l’A7 IV par défaut. Un boîtier Tally Sony par caméra.

À renseigner si plusieurs Sony portent le même nom. Sinon, n’allume qu’une caméra pour le premier appairage.

REC confirméArrêt confirméÉtat inconnu
Appairer le Sony après le flash
  1. Sur le Sony, active Bluetooth et la commande à distance Bluetooth.
  2. Ouvre le menu Appairage, puis démarre le Tally Sony. Confirme la demande sur la caméra.
  3. Lance puis arrête un REC sur la caméra : vérifie le rouge puis l’extinction.

Bleu clignotant : recherche, liaison perdue ou aucun état REC reçu. Maintiens BOOT 4 secondes après démarrage pour oublier l’appairage. Un nouveau flash l’efface aussi.

Avant un tournage, teste aussi un arrêt imprévu et une reconnexion. Ce prototype indique l’état REC reçu ; il ne vérifie pas les fichiers sur la carte mémoire.

La carte n’est pas détectée ?
Utilise un câble USB de données. Ferme les moniteurs série. Pour forcer le mode téléchargement : maintiens BOOT / 0, appuie puis relâche RST, puis relâche BOOT. Actualise ensuite les ports.
Le flash déclenche un redémarrage automatique. Si la carte ne revient pas, débranche puis rebranche son alimentation USB. Le numéro de caméra reste mémorisé ; il peut toujours être modifié ensuite avec BOOT.
